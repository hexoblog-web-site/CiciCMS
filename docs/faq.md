# 常见问题

按场景分组。找不到答案的，去 [代码手册](/dev/) 或 [部署运维](/ops/) 翻。

## 安装

**装完访问首页是空白 / 目录列表**

根目录没有 `index.html`。后台「生成静态」点一次全量生成。如果报"写入失败"，看 [目录权限](/guide/requirement#目录权限)。

**安装第一步报"目录不可写"**

把站点根目录和 `content/` 改成 755，属主设为 PHP 运行用户（宝塔是 `www`）。

**装完忘了后台地址**

`http://你的域名/admin/`。

**忘了管理员密码**

数据库里改。用 phpMyAdmin 执行：

```sql
UPDATE cms_user
SET password = '$2y$10$……'
WHERE username = 'admin';
```

`$2y$10$……` 这一段要自己生成：随便找个 PHP 环境跑 `echo password_hash('新密码', PASSWORD_DEFAULT);`。

**想重装**

删 `config.php` + `content/data/install.lock`，清空数据表，再访问 `/install/`。

## 使用

**改了文章，前台没变**

没生成。后台「生成静态」点一次；或者在「系统设置」打开"保存后自动生成"。

**文章页 404**

三种可能：

1. 文章还是"草稿"状态
2. 栏目别名被改过（旧地址不作跳转）
3. 没生成静态页

**栏目删不掉**

栏目下还有文章。先把文章改到别的栏目，或者删掉文章。

**上传图片报"不是有效图片"**

文件本身不是图片，或者是 SVG / BMP（这两种故意不收）。换成 jpg / png / gif / webp。

**附件传不上去**

主机 `php.ini` 的 `upload_max_filesize`、`post_max_size` 小于 20MB。程序取"程序上限"和"php.ini 上限"里更小的那个，所以要改 php.ini。

**附件传了但前台没显示**

「文章页底部显示下载按钮」这个勾**默认不勾**。回去勾上，再生成一次。

**正文的换行不见了**

HTML 会把连续空白压成一个空格。要分段就写 `<p>…</p>`，摘要可以用 `|nl2br`。

**标签云里有些标签点进去是空的**

那个标签下的文章都被删了或改成草稿。标签是扫文章表算出来的，重新生成时会消失。

## 模板

**改了模板前台没变**

静态页是"拍照"，改模板只是改"布景"。重新生成一次。

**启用新主题后全站 500**

新主题缺文件。对照 [必备的 13 个文件](/use/theme#必备的-13-个文件) 补全，或看 `content/data/logs/` 里缺哪个。

**标签写错了怎么办**

标签模板写错不会白屏，会原样输出成文字。看到页面上出现 `{cici:xxx}` 就是那里没解析。

**`{cici:if}` 不生效**

变量要带 `$`：`{cici:if $post.cover}`，不是 `{cici:if post.cover}`。

**想加一个自己的标签**

在 `includes/tags/single/` 或 `block/` 下建一个文件，注册表会自动扫到。参考已有标签的写法，见 [标签引擎](/dev/#标签引擎)。

## 生成

**生成报"写入失败"**

根目录不可写。755 + 属主对。

**生成到一半停住**

PHP 执行时间或内存不够。到「系统设置」关掉"保存后自动生成"，分批手动生成。程序本身已经按 8 秒一批在做，但如果单个页面渲染就超时，还是会被打断。

**生成完了错误数不是 0**

看 `content/data/logs/` 当天的日志，会写清楚是哪个模板、什么错。

**生成很慢**

文章过千以后属正常。优化方向：关自动生成、攒批处理、调大 `max_execution_time`。

**清空静态文件后前台打不开**

清空只删磁盘上的 HTML/XML，数据库没动，所以前台所有页面会变成 404（不是 500）。进后台点一次「全量生成」即可恢复；如果连后台都打不开，再看 PHP 错误日志。

## 更新

**检查更新一直失败**

主机禁了外网请求，或者访问不了 GitHub。用手动覆盖升级，见 [升级](/guide/upgrade#manual)。

**更新到一半报错**

程序会自动回滚。看日志原因，多半是 `includes/` 属主不是 PHP 运行用户，`chmod` 失败。

**更新完白屏**

看 `content/data/logs/`。最常见是主题用了新版删掉的标签，或者 PHP 版本太低。用「回滚」退回上一版再排查。

**邮件发不出去**

- `mail()` 方式：主机没装 `sendmail` / msmtp，或者禁用了 `mail()`
- SMTP 方式：QQ/163 要填**授权码**不是登录密码；服务器要能连 465/587
- 点「发一封测试邮件」看具体报错，比如 `535 Authentication failed`

## 性能

**能上 CDN 吗**

可以，整站都是静态文件。注意 HTML 缓存时间设短一点。

**数据库挂了前台还能访问吗**

能。静态文件不查库。只有后台和搜索会挂。

**访客多了会慢吗**

不会明显变慢。压力在文件读取上，跟发图片一个量级。

**需要 Redis 吗**

不需要。

## 安全

**后台被人试着登录怎么办**

程序有 15 分钟 8 次的限速。想更严：在 Nginx 上给 `/admin/` 加 IP 白名单，或者加一层 Basic Auth。

**上传目录会不会被传马**

后缀白名单 + 真实类型校验 + 目录禁止执行，三道关。但**插件目录例外**，见下一条。

**插件安全吗**

插件就是 PHP，权限和程序一样。**只装你信得过的**。不需要插件就删掉整个 `content/plugins/` 目录，风险归零。详见 [权限模型](/ops/permission#exceptions)。

**`config.php` 会不会被人下载**

Apache 靠根目录 `.htaccess` 挡住；Nginx 必须自己配规则。检查方法：浏览器访问 `/config.php`，应该是 403 或 404。

**被挂马了怎么办**

1. 后台「数据系统」备份数据库，下载
2. 把 `content/uploads/` 打包下载（检查里面有没有 `.php`）
3. 用同版本程序**完整覆盖** `includes/`、`admin/`、根目录 `.php`
4. 改数据库密码、后台密码、SMTP 授权码
5. 逐个检查 `content/themes/` 和 `content/plugins/` 里的文件

## 已知限制 {#limits}

这些是**故意没做**或者**暂时做不了**的，不是 bug：

| 限制 | 说明 |
| --- | --- |
| 没有评论 | 需要的话接第三方（如 Waline、Twikoo） |
| 没有会员 / 注册 | 单管理员模型 |
| 没有多管理员权限分级 | `user` 表支持多行，但没做角色字段和权限判断 |
| 栏目只有一级 | `parent_id` 留了，后台没做多级界面 |
| 标签不能自定义路径 | 用名字 MD5 前 10 位当文件名 |
| 归档不分页 | 按年分组的单页；文章过万建议自己改 |
| 正文不支持完整 Markdown | 只支持代码围栏，标题/表格/列表写 HTML |
| 正文分页（`pagebreak`）没做 | — |
| 搜索是动态的 | 静态站想纯静态搜索得接第三方 |
| 不做伪静态 | 输出真实 `.html`，不支持去掉后缀 |
| 代码高亮靠插件 | 停用后代码块是深色面板但没有颜色 |
| 根目录必须可写 | 纯静态方案的固有矛盾 |
