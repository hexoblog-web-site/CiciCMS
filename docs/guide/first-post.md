# 发布第一篇

假设你已经装好并登录了后台。目标是：**写一篇文章，让它在首页出现。**

## 1. 先建一个栏目

文章必须挂在栏目下。第一次安装程序会自带一篇示例文章和它的栏目，你可以直接用，也可以自己建。

进「栏目管理」→ 点「新增」：

| 字段 | 填什么 | 建议 |
| --- | --- | --- |
| 栏目标题 | 显示给人看的名字，如「技术笔记」 | 短一点，导航里放得下 |
| 栏目别名 | 网址里的目录名，只能英文数字，如 `tech` | **定了就别改**，改了老地址直接 404 |
| 关键词 / 描述 | 给搜索引擎看的 | 可以留空 |
| 栏目横幅 | 栏目页顶部背景图 | 可不填 |

保存。

::: danger 栏目别名为什么不能改
它直接就是网址目录：别名 `tech` → 栏目页是 `/tech/`。改了以后旧地址没有任何跳转，之前被收录的链接全变成 404。上线前想清楚。
:::

## 2. 写文章

「文章管理」→「写文章」。

编辑页从上到下就一条线：**标题 → 属性 → 正文 → 摘要 → 发布**。

![文章编辑页](/images/admin/03-article-edit.png)

*属性区挤在一处，常用的都在第一屏，不用来回滚。*

**必填的只有标题和正文**，其余按需。

### 属性区都是干什么的

| 项 | 作用 | 不填会怎样 |
| --- | --- | --- |
| 推荐位 | 推荐 / 头条 / 图片 / 幻灯 / 特荐 / 滚动 / 加粗 / 图文，模板里按这个筛 | 就是普通文章 |
| 分类 | 挂在哪个栏目 | **必选**，不然前台找不到它 |
| 标签 | 逗号分隔，如 `PHP,教程` | 不进标签云 |
| 英文路径 | 网址最后一段，默认是文章 ID | 用 ID，如 `/tech/12.html` |
| 封面 | 列表卡片的图 | 卡片上没图 |
| 附件 | 挂 pdf / zip 等，前台出下载按钮 | 不显示 |
| 摘要 | 列表页的一段话 | 自动从正文截 120 字 |
| 状态 | 已发布 / 草稿 | 草稿前台看不到 |

### 正文怎么写

就是一块普通输入框，**你输入什么就存什么**，程序不会偷偷替换字符、不会自动加 `<p>`、不会把空格变成 `&nbsp;`。

所以：

- 想分段就写 `<p>…</p>`，或者直接空一行（模板里会处理）
- 想加粗写 `<strong>`
- 想插图用工具栏的「图片」按钮

### 插图的两种方式

点工具栏的「图片」，弹窗里有两条路：

**A. 上传本地图片**

拖进去或点选，选完立刻上传，显示缩略图和尺寸，点「插入」就写进光标位置。

**B. 填一个网址**

粘贴 `https://...`，默认勾了「下载到本站」——插入时会先把图抓回自己服务器，再写成本站地址。这样原站以后删图也不影响你。

::: tip 建议勾「下载到本站」
外链图是别人的，人家一删、一防盗链，你文章就开天窗。抓回本地只多占一点空间，图永远在。
:::

::: warning 关于 SVG
上传只接受 jpg / png / gif / webp，**SVG 和 BMP 会被拒绝**。SVG 里能写脚本，等于给攻击者留了个口子，所以直接不收。
:::

### 代码块怎么弄

用三个反引号围起来，后面跟上语言名：

````text
```php
<?php
echo 'Hello';
```
````

保存时会自动转成深色代码面板。装「代码高亮」插件的话还会着色并带复制按钮；不装也有面板，只是没颜色。

## 3. 发布

点页面底部的「保存并生成」（或按 `Ctrl / ⌘ + S`）。如果你在「系统设置」里开了「保存后自动生成」，这时候静态页已经重建完了，刷新前台就能看到。保存后会留在编辑页，方便接着改；想回列表点旁边的「保存并返回列表」。

没开的话，去「生成静态」点一次「全量生成」。

## 4. 检查前台

| 看哪里 | 应该看到 |
| --- | --- |
| 首页 | 文章出现在列表里 |
| 栏目页 `/tech/` | 文章在里面 |
| 文章页 `/tech/12.html` | 正文、面包屑、上下篇 |
| 标签云 `/tags.html` | 你写的标签 |
| 归档 `/archive.html` | 按年月分组 |
| `sitemap.xml` | 有新文章的地址 |

## 常见"发布了但看不到"

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 首页没变 | 没生成 | 「生成静态」点一次 |
| 文章页 404 | 别名/目录不对，或没生成 | 确认文章是"已发布"，再生成 |
| 列表里没图 | 没设封面 | 编辑文章设封面 |
| 正文挤成一坨 | 没分段 | 用 `<p>` 或空行分段 |
| 代码块没颜色 | 高亮插件停用了 | 「插件」里启用「代码高亮」，再生成 |
