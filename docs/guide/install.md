# 安装（图文）

整个过程大约 5 分钟，全程在浏览器里点，不用命令行。

::: tip 关于本文截图
界面还在做最后调整，截图会随定稿统一更新（文件名不变，替换即可）。步骤文字与程序行为是对应的，可放心照着做。
:::

## 准备三样东西

1. **一个能放 PHP 的空间**（虚拟主机 / 宝塔 / 自己搭的都行），并确认满足 [环境要求](/guide/requirement)
2. **一个空数据库**，以及数据库的地址、库名、用户名、密码
3. **程序文件**：下载后解压，把里面**所有文件**（不是外层文件夹）传到站点根目录

::: warning 传完检查一下
传完后站点根目录应该能直接看到 `index.php`、`includes/`、`admin/`、`content/`。如果你看到的是一个叫 `CiciCMS-2.1.9/` 的文件夹，说明多套了一层，把它里面的内容移出来。
:::

## 第一步：打开安装向导

浏览器访问：

```
http://你的域名/install/
```

程序会自动做环境检测，逐项打勾。

![安装第一步：环境检测](/images/install/step1-env.png)

*环境检测页。全绿就可以往下走；出现红叉先按提示解决，别硬装。*

这一页会检查：PHP 版本、`PDO` / `pdo_mysql` / `json` / `mbstring` / `gd` 扩展、目录是否可写、能不能连数据库。

**没通过怎么办**

| 提示 | 处理 |
| --- | --- |
| PHP 版本过低 | 在主机面板把 PHP 切到 7.4 或 8.x |
| 缺少 pdo_mysql | 面板里勾选该扩展，或联系主机商开启 |
| 目录不可写 | 把站点根目录和 `content/` 改成 755 |
| 扩展目录不可写 | 同上，属主设为 PHP 运行用户 |

点「下一步：配置参数」。

## 第二步：填配置

这一页分四组，一路填下来就行。

![安装第二步：参数配置](/images/install/step2-config.png)

*数据库在上一组，站点信息在中间，管理员账号在最下面。*

**① 数据库**

| 字段 | 填什么 |
| --- | --- |
| 数据库地址 | 一般就是 `127.0.0.1` 或 `localhost`；数据库在另一台机器才填 IP |
| 端口 | 默认 `3306`，宝塔有时候是 `3307`，按面板显示填 |
| 数据库名 | 你刚建的那个空库名 |
| 表前缀 | 默认 `cms_`。**同一个数据库里装多个站时必须各不相同** |
| 用户名 / 密码 | 数据库账号，不是主机登录账号 |

**② 站点信息**

| 字段 | 说明 |
| --- | --- |
| 网站名称 | 会显示在标题和页脚，之后能改 |
| 站点地址 | 例如 `http://www.example.com`。**不要以斜杠结尾**，不要带 `/install` |

::: danger 站点地址一定要填对
生成的静态页面里，所有链接都是按这个地址拼出来的。填错了，整站链接全歪；带 `https` 的站就填 `https://`。装完之后也能在「系统设置」里改，但改完**必须重新生成一次**。
:::

**③ 管理员**

| 字段 | 说明 |
| --- | --- |
| 管理员账号 | 登录后台用，建议别用 `admin` |
| 管理员密码 | 至少 6 位，用 `password_hash` 加密存库，数据库里看不到明文 |
| 确认密码 | 再输一遍 |

点「开始安装」。

## 第三步：完成

程序会自动建表、写 `config.php`、建管理员、导入一篇示例文章，然后**顺手生成一次静态页**。

![安装第三步：完成](/images/install/step3-done.png)

*这一页会告诉你生成了多少个文件、后台地址在哪。截图留个底，等下要用。*

看到这一页就装好了。页面上有两件事必须马上做：

::: danger 装完 3 分钟内做完
1. **删掉整个 `install/` 目录** —— 安装向导能重装数据库，留着等于把钥匙插在门上。
2. **把 `config.php` 权限改成 644** —— 里面是数据库密码。
:::

## 第四步：进后台

访问 `http://你的域名/admin/`，用刚才设的账号登录。

![登录页](/images/admin/login.png)

登录后就是仪表盘：

![后台仪表盘](/images/admin/01-dashboard.png)

## 第五步：确认前台是静态的

浏览器打开站点首页，然后看一眼站点根目录——应该多出来 `index.html`、`about.html`、`tags.html`、`archive.html`、`links.html`、`404.html`、`sitemap.xml`、`rss.xml`。

如果根目录**没有** `index.html`，说明生成没成功或者站点根目录不可写：

1. 进后台「生成静态」手动点一次，看报什么错
2. 报"写入失败"就是权限问题，回到 [环境要求](/guide/requirement#目录权限)

## 重装

想推倒重来：

1. 删除 `config.php`
2. 删除 `content/data/install.lock`
3. 清空原来的数据表（或换一个空库）
4. 重新访问 `/install/`

::: warning
`content/` 里的图片、主题、备份不会被这一步清掉。要彻底重来就手动删 `content/uploads/` 和 `content/data/`。
:::

## 装完推荐做的 5 件事

1. 删 `install/`、`config.php` 设 644
2. 后台「系统设置」改站点名称、每页条数、备案号
3. 「系统设置」里把**目录权限自检**跑一遍，看有没有黄色项
4. 「系统更新」里配一个通知邮箱（SMTP 方式更靠谱），以后有新版本会发信
5. 后台「数据系统」点一次「立即备份」，先存一份干净的
