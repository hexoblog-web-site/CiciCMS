# 环境要求

## 最低要求

| 项目 | 要求 | 怎么确认 |
| --- | --- | --- |
| PHP | **7.0 及以上**（推荐 7.4 / 8.0+） | 后台「系统设置 → 系统信息」会显示当前版本 |
| PHP 扩展 | `PDO`、`pdo_mysql`、`json`（**必需**） | 安装向导第一步会逐项打勾 |
| PHP 扩展 | `mbstring`、`gd`（推荐） | 缺 `mbstring` 中文截断可能出乱码 |
| MySQL | **5.6 及以上**（MariaDB 10.x 也行） | 装完在系统信息里能看到版本 |
| Web 服务器 | Apache（认 `.htaccess`）或 Nginx | 虚拟主机都行，不需要 root |
| 磁盘 | 程序本身约 1.5 MB，其余看你传多少图 | — |

::: tip 不需要的东西
不需要 Composer、不需要 Node、不需要 Redis / Memcached、不需要伪静态规则、不需要计划任务（cron 是可选的）、不需要 `ZipArchive` 扩展（在线更新用的是自带的解析器）。
:::

## 目录权限

只需要记两条：

| 目录 | 权限 | 为什么 |
| --- | --- | --- |
| 站点根目录 | **可写**（755，属主是 PHP 运行用户） | 静态 `.html` 要生成到这里 |
| `content/` 整个目录 | **可写**（755） | 图片、缓存、备份、日志都往这里写 |
| `includes/` `admin/` | 建议**只读**（555） | 程序代码不该被改，减少被写马的机会 |
| `config.php` | **只读**（644，装完再改） | 里面是数据库密码 |

::: warning 别用 777
`777` 在部分主机上会让 PHP 拒绝执行（safe_mode 遗留）或直接报 500，而且等于把门敞开。**755 就够**，属主对就行。
:::

::: danger 系统区设只读后，在线更新还能用吗？
能。更新前程序会临时把 `includes/`、`admin/` `chmod` 成可写，结束（无论成功还是回滚）再改回原样。如果 PHP 不是这些目录的属主、连 `chmod` 都不行，会直接拦下并提示你手工改，不会写到一半停住。
:::

## 怎么快速自检

装完之后，进后台「系统设置 → 目录权限自检」，程序会按上面的表逐项核对，**黄色 = 还没落实**，绿色 = 没问题。

如果你还没装，安装向导第一步也会做一遍环境检测。

## 常见主机能不能用

| 场景 | 结论 |
| --- | --- |
| 宝塔面板 + LNMP / LAMP | 可以，注意站点根目录指向程序目录 |
| 阿里云 / 腾讯云虚拟主机 | 可以，选 PHP 7.4+ 的套餐 |
| 只给 PHP 不给 MySQL 的空间 | **不行**（程序要数据库） |
| 纯静态托管（GitHub Pages / OSS） | 只能放**生成之后**的静态结果，后台跑不了 |
| Docker | 可以，PHP 7.4+ + MySQL 两个容器即可 |
| Windows / IIS | 可以跑，但 `.htaccess` 不管用，需要自己配 URL 重写 |
