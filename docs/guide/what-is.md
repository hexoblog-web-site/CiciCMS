# 这是什么程序

## 一句话

**CiciCMS 是一个"后台管理 + 前台生成纯 HTML"的内容管理系统。**

你在后台写文章，点一下"生成"，程序把文章变成一堆 `.html` 文件放到站点目录里；访客打开网站时，服务器直接把这堆 `.html` 递过去，根本不碰数据库。

## 它和常见的 CMS 有什么不一样

大部分 CMS（WordPress、织梦、帝国）是**动态**的：每次有人访问，PHP 都要连数据库、查一遍、拼出页面、再发出去。

CiciCMS 是**静态**的：页面在"你发布的时候"就已经拼好存成文件了，访问时只做一件事——把文件读出来。

| | 动态 CMS | CiciCMS |
| --- | --- | --- |
| 访客打开页面时 | 现场查数据库、拼 HTML | 直接读现成的 `.html` 文件 |
| 服务器压力 | 跟着访客数线性上涨 | 几乎不涨，跟文件服务器一样 |
| 数据库挂了 | 整站打不开 | 前台照常访问（只有后台进不去） |
| 能不能上 CDN | 要特殊配置 | 整站就是静态文件，直接扔上去 |
| 需不需要伪静态 | 需要 | 不需要 |
| 安装 Redis / 缓存插件 | 通常要 | 不需要 |
| 文章更新后多久生效 | 立刻 | 点一次"生成"（或开启自动生成） |

::: tip 只有一件事要注意
"静态"的代价是：**改完内容要生成一次**。程序提供了三种方式，见 [生成静态](/use/build)。开了"保存后自动生成"就完全感觉不到这一步。
:::

## 谁适合用

- **个人博客 / 内容站**：写教程、随笔、专栏，在意打开速度和 SEO
- **企业官网 / 产品站**：页面不多，但要求稳定、别动不动 502
- **买的是虚拟主机**：只给 PHP + MySQL，不给伪静态、不给 Redis、不给 Composer
- **不想学新东西的站长**：后台按国内习惯做，栏目、推荐位、模板这些词你都认识
- **要长期放着不管的站**：没有定时任务也能跑，没有缓存插件也不会越跑越慢

## 谁不适合用

- 需要**评论、会员、多作者权限分级**的站 —— 这些功能没做（见 [已知限制](/faq#limits)）
- 需要**电商、支付、表单收集**的站
- 内容**每分钟都在变**的站（比如实时资讯流），生成跟不上
- 完全不想碰 HTML 的人 —— 默认主题能直接用，但要改样式终归要会一点点 HTML

## 四个必须知道的概念

### 1. 生成（静态化）

后台点"生成静态"→ 程序按模板把数据库里的内容拼成 HTML → 写到站点目录。首页、栏目页、文章页、标签、归档、友链、404、`sitemap.xml`、`rss.xml` 一次全出来。

### 2. 三区

程序把文件分成三块，各管各的：

| 区 | 目录 | 干什么 | 升级时 |
| --- | --- | --- | --- |
| 系统区 | `includes/` `admin/` `install/` | 程序代码 | 整体覆盖 |
| 内容区 | `content/` | 你的主题、图片、插件、备份 | **绝对不动** |
| 入口 | 根目录的 `.php` 和 `config.php` | 门 | 覆盖 php，`config.php` 保留 |

记住一句话就够：**升级只覆盖代码，你的东西一个都不会丢。**

细节和权限设置见 [权限模型](/ops/permission)。

### 3. 模板就是 HTML

主题文件是纯 HTML，里面用 `{cici:xxx}` 这种标签当"会自己变内容的占位符"：

```html
<h1>{cici:post.title}</h1>
<div class="meta">{cici:post.created_at|date:"Y年m月d日"}</div>
<div class="body">{cici:post.content}</div>
```

不用写 PHP，不用学模板语法书。改字、改结构都行，只要别把 `{cici:}` 标签删了。见 [模板开发](/theme/)。

### 4. 插件是"可选的一段 PHP"

插件能改渲染结果、能接管保存动作、能往后台加页面。装它等于让一段 PHP 在你服务器上跑，所以**只装自己信得过的**。见 [插件](/use/plugin)。

## 它自带什么

| 功能 | 说明 |
| --- | --- |
| 文章 / 栏目 / 单页 / 友链 / 标签 | 建站必需的几个内容类型 |
| 推荐位 | 推荐、头条、图片、幻灯、特荐、滚动、加粗、图文 |
| 封面 + 摘要 | 列表页卡片要用 |
| 文章附件 | 挂 pdf / zip / exe 等，前台出下载按钮，默认不显示 |
| 媒体信息 | 集中看上传过的图片 |
| 系统清理 | 找出"没被任何内容引用"的图片和附件，避免白占空间 |
| 数据备份 / 恢复 / 导入 | 后台点按钮，不用进 phpMyAdmin |
| 在线更新 | 和 GitHub 仓库比版本，一键覆盖程序文件，失败回滚 |
| 邮件通知 | 有新版本时发邮件（`mail()` 或 SMTP 都行） |
| 代码高亮 | 可选插件，本地打包，不用 CDN |
| Hexo 导入 | 把 Markdown 批量搬进来，图片一起搬 |
