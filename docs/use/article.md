# 写文章

「文章管理」是每天都要用的页面。这一页把编辑页的每一项都讲清楚。

## 列表页

![文章列表](/images/admin/02-article-list.png)

能做的事：

| 操作 | 说明 |
| --- | --- |
| 搜索 | 按标题、摘要模糊匹配 |
| 按栏目筛 | 只看某个栏目下的 |
| 批量删除 | 勾选后统一删，会同步清理旧静态文件 |
| 置顶 | 列表页显示在前面，模板里可用 `is_top` 判断 |
| 草稿 | 状态改成草稿，前台看不到 |
| 点标题 | 进编辑页 |
| 点"查看" | 打开前台对应页面 |

## 编辑页

从上到下就一条线：**标题 → 属性 → 正文 → 摘要 → 发布**。

![文章编辑页](/images/admin/03-article-edit.png)

::: tip 为什么这么排
因为写文章的真实顺序是这样的：先想标题，再定"这文章归哪儿、要不要推荐"，然后写正文，最后写摘要、点发布。属性放在下面的话，每次都要滚到页尾去选分类，来回折腾。
:::

### 标题

必填。会用来生成 `<title>`、列表标题、`sitemap` 里的标题。

### 属性

| 属性 | 说明 | 不填的后果 |
| --- | --- | --- |
| **分类** | 挂在哪个栏目下 | **必选**，否则前台找不到 |
| **推荐位** | 打标记，模板按标记筛选 | 就是普通文章 |
| 标签 | 逗号分隔，如 `PHP,教程` | 不进标签云、不能按标签筛 |
| 英文路径 | 网址最后一段，如 `hello-world` | 用文章 ID，如 `/tech/12.html` |
| 封面 | 列表卡片、文章头图用的图 | 卡片没图 |
| 附件 | 挂一个文件，前台出下载按钮 | 不显示 |
| 状态 | 已发布 / 草稿 | 草稿前台看不到 |
| 置顶 | 列表里往前排 | 不置顶 |

#### 推荐位都有哪些

| 代号 | 名称 | 一般用在哪 |
| --- | --- | --- |
| `c` | 推荐 | 首页推荐区 |
| `h` | 头条 | 大图头条 |
| `p` | 图片 | 图文卡片 |
| `f` | 幻灯 | 轮播 |
| `a` | 特荐 | 特别推荐栏 |
| `s` | 滚动 | 滚动条 |
| `b` | 加粗 | 列表里标题加粗 |
| `j` | 图文 | 图文混排 |

模板里这样用：

```html
{cici:list flag="c" limit="5"}
  <a href="{cici:item.url}">{cici:item.title}</a>
{/cici:list}
```

::: tip 一个人可以打多个标记
推荐位可以多选。实战里常见的组合是"推荐 + 图片"，首页既进推荐区、又有封面图。
:::

#### 英文路径（slug）

- 不填：用文章 ID，网址是 `/tech/12.html`
- 填了：网址变成 `/tech/hello-world.html`
- 只能是英文、数字、连字符，**不能重复**

::: warning 定了别改
改了以后老地址直接 404，程序不做跳转。已经被收录的链接就废了。
:::

### 正文

一块纯 textarea 输入框。特点：

- **输入什么存什么**，不替换字符、不自动加 `<p>`、不转义
- 支持 HTML，想加粗就写 `<strong>`
- 代码块用三个反引号围起来

```text
```php
<?php echo 'hi';
```
```

保存时自动变成深色代码面板。装了「代码高亮」插件会着色 + 带复制按钮。

#### 插图

点工具栏「图片」，弹窗里两种方式：

**上传本地文件**：拖进去或点选，立刻上传，显示缩略图和尺寸，点「插入」写进光标位置。

**填网址**：粘贴 `https://...`，默认勾选「下载到本站」——插入前先把图抓回服务器，再写成本站地址。

::: tip 强烈建议勾「下载到本站」
外链图在别人服务器上，人家删了、或者开了防盗链，你文章就开天窗。抓回本地只多占一点空间。
:::

存储规则：

| 项 | 规则 |
| --- | --- |
| 目录 | `content/uploads/images/年/月日/`，如 `2026/1105/` |
| 文件名 | 8 位日期 + 16 位微秒时间戳，如 `2026110516996682087272.png` |
| 格式 | jpg / jpeg / png / gif / webp |
| 上限 | 单张 5MB |

SVG 和 BMP 一律拒绝——SVG 里能写脚本，是个口子。

#### 替代文字（alt）

弹窗里有一栏「替代文字」，建议填一句人话。作用是：图片加载失败时显示这句、读屏软件念这句、图片搜索能收到。

### 摘要

列表页卡片上的一段话。留空的话，程序自动从正文截前 120 字（先去掉 HTML 标签）。

### 附件

属性区最下面一行「附件（可选）」，用来挂文档、压缩包、小软件。

| 支持 | 单个上限 |
| --- | --- |
| pdf / doc(x) / xls(x) / ppt(x) / txt / md / csv / rtf | 20MB |
| zip / rar / 7z / gz / tar | 20MB |
| exe / msi / apk / dmg / ipa / pkg | 20MB |

三个字段：

1. **选择文件** —— 传完地址自动填进输入框，也可以直接粘一个下载地址
2. **下载按钮上的名字** —— 前台显示的文件名，留空用原始文件名
3. **文章页底部显示下载按钮** —— **默认不勾**

::: warning 传了不等于会显示
不勾第三项，前台什么都不显示。这样你可以先把文件存着备用，或者这期先不发。
:::

文件落在 `content/uploads/files/年/月日/`，目录里会自动写一份禁止执行脚本的 `.htaccess`。

附件**不进**媒体信息（那是图片画廊），但系统清理扫得到，只要还被文章引用就不会被删。

模板里这样取：

```html
{cici:if $post.attach_show}
<a href="{cici:post.attachment}" download>
  {cici:post.attach_name}（{cici:post.attach_size|size}）
</a>
{/cici:if}
```

### 发布

在页面底部那条常驻操作条上点「保存并生成」，也可以按 `Ctrl / ⌘ + S`。保存后会**停在编辑页**，方便接着改或弹窗预览；点旁边的「保存并返回列表」才回到列表。文章、单页、栏目都是这套行为。

- 开了"保存后自动生成" → 静态页立刻重建，刷新前台就能看到
- 没开 → 去「生成静态」点一次
- 想看未保存的效果 → 点「预览」，在当前后台窗口弹窗渲染，草稿也能看

## 常见问题

**正文里的换行不见了**
textarea 里的换行存进库是 `\n`，浏览器渲染 HTML 时会把连续空白压成一个空格。要分段就写 `<p>…</p>`，或者在模板里对摘要用 `|nl2br`。

**图片插进去但是裂的**
看地址是不是 `/content/uploads/...` 开头。如果是 `file:///` 或本机路径，说明插入时用的不是上传，而是直接写的本地路径。

**附件传不上去**
主机 `php.ini` 的 `upload_max_filesize` 和 `post_max_size` 可能小于 20MB。程序会取"程序上限"和"php.ini 上限"里更小的那个，所以实际能传多大取决于主机配置。

**保存很慢**
文章多了以后每次保存都重建静态页会慢。到「系统设置」关掉"保存后自动生成"，改成批量手动生成。
