# 栏目管理

栏目就是"文章的分类目录"，同时也是**网址目录**。建一个别名 `tech` 的栏目，它的页面就是 `/tech/`。

![栏目列表](/images/admin/04-category-list.png)

## 一个设置页管六项

点「编辑」进去，所有栏目设置挤在一页：

![栏目编辑](/images/admin/05-category-edit.png)

| 项 | 作用 | 注意 |
| --- | --- | --- |
| 栏目标题 | 显示给人看的名字，如「技术笔记」 | 短一点，导航里放得下 |
| 栏目别名 | 网址目录名，英文数字 | **定了不能改** |
| URL | 栏目的实际地址，由别名算出来 | 只读 |
| 关键词 | 给搜索引擎看的 | 可留空 |
| 描述 | 栏目页的 `<meta description>` | 可留空 |
| 栏目横幅 | 栏目页顶部背景图 | 可上传，也可填外链 |

## 栏目别名为什么不能改

它直接就是网址目录：

```
别名 tech  →  栏目页 /tech/
             文章页 /tech/12.html
```

改了以后，旧地址**没有任何跳转**，之前被搜索引擎收录的、别人收藏的链接全部 404。

::: danger 上线前想清楚
建站阶段随便改，上线之后就别动了。真的必须改，得自己到服务器上配 301 跳转规则，程序不代劳。
:::

## 栏目横幅（Banner）

栏目页的页头背景图。两种填法：

1. **点「上传」** 传一张图，地址自动填进输入框
2. **直接粘外链**，比如 `https://cdn.example.com/banner.jpg`

模板里这样取：

```html
<div class="cat-header" style="background-image:url({cici:cat.banner_url})">
  <h1>{cici:cat.name}</h1>
  <p>{cici:cat.description}</p>
</div>
```

没设横幅时 `banner_url` 是空串，模板里用 `{cici:if $cat.banner_url}` 判断一下，避免出现一个空的背景容器。

## 删除保护

**栏目下还有文章时，不允许删除。**

这不是限制你，是防止误操作：一删栏目，那些文章就没有归属了，前台找不到，等于数据丢了。

要删栏目，先处理里面的文章：

1. 把文章改到别的栏目，或者
2. 把文章删掉

然后再删栏目。

## 栏目只有一级

程序目前是**单级栏目**结构：

```
✓ 技术笔记
✓ 乡土风物
✗ 技术笔记 → PHP  → 框架     （不支持三级嵌套）
```

数据库里 `parent_id` 字段是留着的，面包屑也支持多级链路，但后台没做多级管理界面。如果你的站确实需要二级分类，两个变通办法：

- 用**标签**代替二级分类（标签可以任意多、任意组合）
- 一个栏目对应一个主题，文章用标签再细分

## 栏目和导航

顶部导航一般直接循环栏目：

```html
{cici:nav type="top"}
  <a href="{cici:item.url}" class="{cici:item.currentstyle}">{cici:item.name}</a>
{/cici:nav}
```

`currentstyle` 在当前栏目上会自动变成 `active`，用来高亮。

## 新建栏目的建议顺序

1. 先想好网址目录名（英文、短、有意义）
2. 建栏目，填标题和别名
3. 填关键词和描述（对 SEO 有用）
4. 传一张横幅（可选）
5. 去写第一篇文章，挂到这个栏目下
6. 「生成静态」一次，栏目的 `index.html` 才会真的出现

::: tip 为什么删了栏目，目录还在
生成器只删自己写过的文件。删栏目后，旧的栏目目录（`/tech/index.html`）在下一次全量生成时会被清理掉。如果没清，点一次「生成静态 → 清空静态文件」再生成。
:::
