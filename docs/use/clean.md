# 系统清理

写了几年之后，`content/uploads/` 里一定躺着一堆"改稿留下的废图"。这个页面帮你把它们找出来。

![系统清理](/images/admin/10-clean.png)

## 它怎么判断"没被引用"

扫描 `content/uploads/` 下的**每一个文件**，逐个检查文件名有没有出现在下面这些地方：

| 检查范围 | 具体 |
| --- | --- |
| 文章 | 正文、编辑源文、摘要、封面、附件地址 |
| 单页 | 正文、编辑源文 |
| 栏目 | 横幅地址 |
| 友链 | Logo 地址 |
| 系统设置 | 每一个配置值 |
| 模板 | 当前主题的所有模板文件 |

只要在上述**任何一处**出现过，就算"正在使用"，不会出现在待清理列表里。

::: tip 这是故意保守的口径
宁可少清理几张，也不能误删正在用的图。本系统上传的文件名带时间戳和随机串，撞名的概率可以忽略，所以"按文件名匹配"足够准。
:::

## 两类条目

### 未使用的文件

文件在磁盘上，但没有任何内容引用它。勾选后删除会**同时删文件和记录**。

### 失效记录

媒体信息里登记了，但**文件已经不在了**（手动 FTP 删了、搬迁时漏传了）。

这种删除时**只清记录，不动磁盘**——因为磁盘上本来就没有。

## 删除时的两道保险

你看到的列表可能是几分钟前扫描的，期间你可能刚好在另一篇文章里插了一张图。所以提交后：

1. **重新建一次引用索引**，再核对一遍 —— 这段时间新插入的图会被跳过
2. **只删 `content/uploads/` 内的文件** —— 绝对路径与 `..` 一律拒绝

主题图片（`content/themes/`）不参与扫描，也不参与删除。

## 什么不会出现在列表里

| 类型 | 原因 |
| --- | --- |
| 文章附件 | 有文章引用着，算"在用" |
| 栏目横幅 | 被栏目引用 |
| 友链 Logo | 被友链引用 |
| 模板里写死的图 | 扫模板时命中 |
| 系统设置里的图（如站点 Logo） | 扫配置值时命中 |

## 反向情况：图还在，但记录没了

如果只用 FTP 传了图、没经过上传器，它不会出现在媒体信息里，也不会被清理（因为清理只扫有记录的文件）。

这种情况程序不管，你自己心里有数就行。

## 什么时候该跑一次

- 改版之后（很多旧图不再需要）
- 换主题之后
- 几个月一次的例行维护
- 空间快满了

::: warning 清理前先备份
虽然有两道保险，但删文件是不可逆的。先到「数据系统」备份数据库，再把整个 `content/uploads/` 打包下载一份，然后再清。
:::

## 界面上的数字怎么读

| 数字 | 含义 |
| --- | --- |
| 共 N 个文件 | `content/uploads/` 下所有文件数（含失效记录） |
| 已用 | 被引用的 |
| 未用 | 没被引用的，可以删 |
| 占用空间 | 这些文件加起来多大 |
