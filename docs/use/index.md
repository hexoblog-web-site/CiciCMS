# 后台地图

访问 `http://你的域名/admin/`，登录后就是后台。左侧菜单按工作流分成四组，组标题可以点击折叠，状态会记住；**当前所在组始终展开**，不会把正在用的入口收起来。

| 分组 | 包含 |
| --- | --- |
| 内容 | 仪表盘、文章管理、栏目管理、单页管理、媒体信息、友情链接 |
| 发布与维护 | 生成静态、系统清理、数据系统 |
| 外观与扩展 | 模板管理、插件管理 |
| 系统 | 系统更新、系统设置 |

插件往菜单里加的项会自动排到它相邻的那一组（例如紧跟在「文章管理」后面的导入工具归到「内容」）。

下面按使用频率再看一遍：

| 菜单 | 干什么 | 频率 |
| --- | --- | --- |
| 仪表盘 | 看统计、快捷入口、最近文章 | 每次登录 |
| 文章管理 | 写、改、删文章 | 每天 |
| 栏目管理 | 建栏目、改栏目设置 | 建站时 |
| 单页管理 | 关于我们、联系方式这类独立页 | 建站时 |
| 媒体信息 | 看上传过的图片 | 偶尔 |
| 友情链接 | 友链的增删改 | 偶尔 |
| 生成静态 | 手动重建静态页 | 改完样式后 |
| 系统清理 | 清理没用到的图和附件 | 几个月一次 |
| 数据系统 | 备份、恢复、导入 | 改大动作前 |
| 模板管理 | 切换主题、在线改模板 | 改版时 |
| 系统设置 | 站点信息、权限自检、改密码 | 建站时 |
| 插件管理 | 启用/停用插件、进入插件自带页面 | 装插件时 |
| 系统更新 | 检查新版本、更新、回滚 | 有新版本时 |

## 仪表盘

![后台仪表盘](/images/admin/01-dashboard.png)

四张卡分别是：

| 卡 | 含义 |
| --- | --- |
| 已发布 | 前台能看到的文章总数 |
| 累计浏览 | 所有文章的浏览量之和（靠 `api.php` 计） |
| 静态文件 | 当前生成出来的 HTML 数量 |
| 运行状态 | 版本、PHP、数据库连接是否正常 |

下面一排十个小方块是快捷入口：写文章、栏目、单页、媒体、生成、数据系统、清理、模板、友链、设置。再往下是「近 7 日发布」柱状图和最近改过的文章，点标题直接进编辑。

::: tip 顶上那条横幅
有新版本时，仪表盘顶部会出现一条提示，点「查看」跳到系统更新页。不想看到它就去更新。
:::

## 外观设置与预览

顶栏右边有两个圆形小按钮：

- **太阳 / 月亮**：切换浅色与深色主题。首次使用跟随操作系统，手动切换后记住选择。
- **四道横线**：切换舒适 / 紧凑密度，紧凑模式会收紧卡片内边距和表格行高，一屏能多看好几行。

![深色主题](/images/admin/13-theme-dark.png)

写文章、写单页时的「预览」按钮会**在当前后台窗口弹窗**，按编辑器里尚未保存的内容渲染，草稿也能看。弹窗右上角的「打开静态页 ↗」才是打开前台真实静态文件。前台因此没有任何动态预览地址。

![内容预览弹窗](/images/admin/14-preview-modal.png)

## 页面布局的规律

后台所有页面都长一个样，记住一次就够：

```
┌─────────────────────────────────────┐
│ 顶栏：页面标题 / 访问前台 / 主操作    │
├────────┬────────────────────────────┤
│ 分组   │ 卡片：筛选条 / 表单 / 表格   │
│ 导航   │ 编辑页底部：常驻保存条       │
│ +退出  │                            │
└────────┴────────────────────────────┘
```

- **列表页的主操作在顶栏右上角**（写文章、新建单页等）；进入编辑/新建态后换成「← 返回列表」
- **文章、单页、栏目保存后停在编辑页**，方便立刻微调或预览；想回列表就点「保存并返回列表」。写长文时底部保存条一直可见，`Ctrl / ⌘ + S` 直接保存
- **列表筛选**：文章页支持关键词、分类、状态筛选与分页；其余列表按固定顺序展示
- **危险操作是红色**，统一走二次确认；批量勾选目前只有「系统清理」提供

## 几个通用操作

**改完内容前台没变？**
去「生成静态」点一次。或者到「系统设置」打开"保存后自动生成"，以后就不用手动点了。

**编辑器里的图片**
用工具栏的「图片」按钮，既能传本地文件，也能填网址（会自动抓回本站）。见 [写文章](/use/article#插图)。

**写到一半被踢出登录**
会话两小时不活动会过期。重新登录后会自动回到刚才那一页（包括正在编辑的文章），不会被扔回仪表盘。

**不小心删了怎么办**
文章删了就是删了（没做回收站）。但**静态文件**在删除时会同步清理，不会留一堆孤立的 HTML。重要的内容建议定期备份数据库。

**忘了密码**
后台登录不了，用数据库改：把 `cms_user` 表的 `password` 字段换成一个新 `password_hash()` 的值。或者删 `config.php` 重装（会丢数据，不建议）。
