# 媒体信息

「媒体信息」是**图片的总览页**：所有通过上传器传进来的图，都在这里列出来。

![媒体信息](/images/admin/07-media.png)

## 它能做什么

| 操作 | 说明 |
| --- | --- |
| 看缩略图 | 列表里直接显示，不用点开 |
| 复制地址 | 一键复制图片的完整 URL，粘到正文或模板里 |
| 删除 | 删文件 + 删登记记录 |

## 这里**不**放什么

| 类型 | 去哪看 |
| --- | --- |
| 文章附件（pdf / zip / exe） | 不进这里。附件地址在文章编辑页的「附件」栏里 |
| 主题自带的图 | 不进这里。它们在 `content/themes/你的主题/assets/` |
| 手动 FTP 传上去的图 | 不进这里。程序不知道你传了 |

::: tip 为什么附件不进来
这张表本质是个**图片画廊**，靠缩略图浏览。把 zip、exe 塞进来，网格会被撑破，而且根本没有预览可看。附件在文章里管理更自然。
:::

## 图片是怎么进来的

只有一条路：**经过上传器**。三个地方都会调它：

- 文章编辑器的「图片」按钮
- 栏目设置里的「栏目横幅」
- 媒体信息页的上传

三个地方走的是同一套规则（`includes/uploader.php` 里的 `Cms_Image_Uploader`）：校验 → 改名 → 落盘 → 登记。所以不会出现"这里能传那种不能传"的不一致。

## 存储和命名

| 项 | 规则 |
| --- | --- |
| 目录 | `content/uploads/images/年/月日/`，如 `content/uploads/images/2026/1105/` |
| 文件名 | 8 位日期 + 16 位微秒时间戳，如 `2026110516996682087272.png` |
| 格式 | jpg / jpeg / png / gif / webp |
| 单张上限 | 5MB |

::: tip 为什么要改成时间戳名
两个原因：一是避免中文名、空格名在各种环境下的编码问题；二是**避免覆盖**——两个人同时传 `1.jpg`，不会互相顶掉。副作用是文件名不好看，但对站点来说无所谓，搜索引擎看的是 alt 和上下文。
:::

## 真实类型校验

程序判断"这是不是图片"，用的是 `getimagesize()` 读文件头，**不看后缀名**。

所以：

- 把一个 `.php` 改名成 `.jpg` 传上来 → 拒绝
- 把一张 1×1 的透明 gif 改名成 `.png` 传上来 → 按真实类型存成 gif
- 一个根本没图片头的文件 → 拒绝

## 删除要注意

在媒体信息里删图，**程序不会检查这张图有没有被文章引用**。

如果那张图还在某篇文章里用着，删了以后文章里就是红叉。

::: danger 想清理废图，用「系统清理」
「系统清理」会先扫描所有内容里的引用，只列出**没被任何地方引用**的文件。它比手动在这里删安全得多。见 [系统清理](/use/clean)。
:::

## 图片不显示怎么办

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 后台缩略图裂 | `content/uploads/` 权限不对 | 改 755 |
| 前台图片裂，后台正常 | 静态页没重新生成 | 生成一次 |
| 前台图片 404 | 文件被删了 | 看文章里引用的是哪张，重新上传 |
| 上传报"不是有效图片" | 文件本身不是图片，或是 SVG/BMP | 换格式 |
