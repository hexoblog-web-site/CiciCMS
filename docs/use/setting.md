# 系统设置

一个页面管站点信息、内容行为、安全三块，最下面还有目录权限自检和系统信息。

![系统设置](/images/admin/12-setting.png)

## 站点信息

| 项 | 作用 | 填错会怎样 |
| --- | --- | --- |
| 网站名称 | 显示在标题、页脚、后台 | 前台到处都是旧名字 |
| 站点描述 | `<meta description>` 的默认值 | 搜索结果里描述空了 |
| 关键词 | `<meta keywords>` | 影响很小，可留空 |
| **站点地址** | 生成静态页时拼链接用 | **填错整站链接全歪** |
| 备案号 | 页脚显示 | 合规问题 |
| 页脚 HTML | 原样输出的 HTML 片段 | 见下面警告 |

### 站点地址要注意什么

- 带协议：`https://www.example.com`
- **不要以 `/` 结尾**
- 不要带 `/admin`、`/install`
- 是 `https` 的站就写 `https`，否则浏览器会报混合内容

::: danger 改完必须重新生成
静态页里的链接是**生成那一刻**按站点地址拼死的。改了地址不重新生成，前台所有链接还指着老地址。
:::

### 页脚 HTML 为什么危险

这个字段是**按设计原样输出**的——不转义、不过滤。也就是说，它等于"管理员可以在全站每个页面注入任意 HTML/JS"。

- 放统计代码、客服脚本 → 正常用法
- **不要**把后台账号给不可信的人 —— 后台账号本身就是最高权限，能改这个字段就能做任何事

## 内容设置

| 项 | 说明 | 建议 |
| --- | --- | --- |
| 每页条数 | 列表页一页显示多少篇 | 10–20 |
| 时区 | 影响文章时间、归档分组 | 国内选 `Asia/Shanghai` |
| 保存后自动生成 | 发文章后自动重建静态页 | 文章少 → 开；文章多 → 关 |

::: tip 自动生成该不该开
| 情况 | 建议 |
| --- | --- |
| 文章 100 篇以内 | **开**，发完立刻生效，体验最好 |
| 文章 500 篇以上 | **关**，改成每天集中生成一次 |
| 主机 PHP 超时限制很严（30 秒） | 关 |

关掉之后记得养成习惯：改完内容去点一次「生成静态」。
:::

### 采信 X-Forwarded-For

| 你的情况 | 该不该勾 |
| --- | --- |
| 站点直接对外，没用 CDN / 反代 | **不勾** |
| 用了 Cloudflare、又拍云、Nginx 反代 | **勾** |

不勾的时候，程序只认 TCP 连接的真实 IP，最可靠。

但如果前面挡了一个 CDN，所有访客在程序看来都是 CDN 的 IP。这时登录限速会把所有人算成同一个 IP——一个人输错 8 次，全站都登不进来。勾上之后才采信请求头里的真实 IP。

::: warning 反过来也有风险
没走 CDN 却勾了这个，攻击者可以伪造 `X-Forwarded-For` 绕过登录限速。所以**只有确实在代理后面才勾**。
:::

## 修改密码

要输旧密码 + 新密码两遍。新密码用 `password_hash()` 存，数据库里看不到明文。

::: tip 密码建议
12 位以上、大小写数字符号混着来。别用站名、别用 `admin123`、别和别处复用。
:::

## 目录权限自检

按 [权限模型](/ops/permission) 的规则逐项核对，每个目录给出"可写/可执行"的判断：

| 颜色 | 含义 |
| --- | --- |
| 绿 | 符合预期 |
| 黄 | 还没落实，建议处理 |

**它检查的是"权限位"，不是"有没有被入侵"**。黄色项不会让站立刻出事，但等于少了一道保险。

::: warning 它有一件事查不到
`content/plugins/` 本来就必须可写，自检不会提示它。但那个目录是"能写又能执行"的，风险最高。详见 [权限模型](/ops/permission#exceptions)。
:::

## 系统信息

| 项 | 用途 |
| --- | --- |
| 程序版本 | 出问题时先报这个 |
| PHP 版本 | 判断能不能用新语法、有没有兼容问题 |
| MySQL 版本 | 同上 |
| 当前模板 | 确认是不是你以为的那套 |
| 数据库连接 | 显示"正常"就说明 `config.php` 里的账号密码对 |

提问求助时，把这一屏截图发出来，能省一半沟通。

## 保存后

大部分设置保存后**需要重新生成**才在前台生效（站点名称、页脚、每页条数都算）。

密码和权限相关的设置立刻生效。
