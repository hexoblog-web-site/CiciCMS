# 模板管理

「模板管理」是换主题、改模板的地方。

![模板管理](/images/admin/11-theme.png)

## 换主题

`content/themes/` 下每个子目录就是一个主题。装好程序自带的只有一个 `default`。

想加新主题：把主题文件夹整个传到 `content/themes/` 下，刷新这个页面，列表里就多一个，点「启用」即可。

::: warning 启用 ≠ 生效
启用之后只是"以后生成时用这套模板"。**已经生成的静态页还是旧样子**，要点一次「生成静态 → 全量生成」。
:::

## 必备的 13 个文件

主题目录里缺一个，对应的页面就会 500。完整清单：

```
header.html     页头（<!DOCTYPE> 到 <body> 开头）
footer.html     页脚（</body> 到 </html>）
index.html      首页
list.html       栏目页 + 标签详情页
loop.html       列表循环片段（被 include）
article.html    文章页
page.html       单页
tags.html       标签云
archive.html    归档
search.html     搜索结果
links.html      友链页
404.html        404
style.css       样式
```

`assets/` 目录是可选的，放主题自带的图片、字体、脚本。

## 在线编辑

点文件名就能在浏览器里改，保存即写入磁盘。

**每次保存前，程序会把原文件备份到：**

```
content/data/backup/theme/<时间>-<文件名>
```

改坏了？

1. 去上面的目录找到刚才那份备份
2. 复制回 `content/themes/你的主题/`
3. 或者直接在后台把备份内容贴回去

::: tip 改模板前先做什么
先点一次「生成静态」确认当前是好的状态，再去改。这样出问题时你知道"刚才那份是好的"。
:::

## 两种模板可以混用

| 类型 | 文件 | 适合谁 |
| --- | --- | --- |
| 标签模板（推荐） | `xxx.html` | 会 HTML 就行，`{cici:}` 当占位符 |
| PHP 模板（高级） | `xxx.php` | 需要复杂逻辑，比如调第三方接口 |

**同名文件同时存在时，`.html` 优先。** 所以想临时切回 PHP 版，把 `.html` 改个名就行。

::: danger PHP 模板写错会整站白屏
标签模板写错只是那一个标签不解析，页面还能看。PHP 模板一个语法错误就是 500，而且前台没有任何提示。没有 PHP 基础就别碰。
:::

## 文件名的规则

| 允许 | 不允许 |
| --- | --- |
| `article.html`、`list-tech.html`、`_part.html` | `../index.php`、`/etc/passwd`、带 `/` 的路径 |

程序对文件名做了正则校验 + `realpath` 前缀校验，只能改主题目录里自己的文件。

## 常见问题

**改了模板，前台没变**
没有重新生成。静态页是"拍照"，你改的是"布景"，得重新拍一张。

**保存提示失败**
`content/themes/` 不可写。改 755。

**主题列表里看不到我传的主题**
目录里必须有 `index.html` 或 `index.php` 才会被识别。

**启用新主题后整站 500**
新主题缺文件。看日志 `content/data/logs/`，会写清楚缺哪个模板。
