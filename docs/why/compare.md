# 和别的方案比

选型没有绝对好坏，只有合不合适。这一页尽量说实话。

## 一张表看完

| | CiciCMS | WordPress | 织梦 / 帝国 | Hexo / Hugo | 常见国产 CMS |
| --- | --- | --- | --- | --- | --- |
| 形态 | PHP + MySQL，输出静态 | PHP + MySQL，动态 | PHP + MySQL，动态 | 本地生成，无后台 | PHP + MySQL，动态 |
| 前台访问时查库 | 否 | 是 | 是 | 否 | 是 |
| 需要伪静态 | 否 | 是（要配） | 是 | 否 | 通常要 |
| 需要命令行 | 否 | 否 | 否 | **是** | 否 |
| 有后台管理 | 有 | 有 | 有 | **没有** | 有 |
| 虚拟主机能跑 | 能 | 能 | 能 | 不能（要本地环境） | 能 |
| 插件生态 | 2 个自带 | **极丰富** | 多（多为付费） | 丰富 | 一般 |
| 主题生态 | 默认 1 套 | **极丰富** | 多 | 丰富 | 一般 |
| 上手难度 | 低 | 中 | 中 | 中高 | 低 |
| 评论 / 会员 | 无 | 有 | 部分有 | 靠第三方 | 部分有 |
| 安全记录 | 新程序，代码量小 | 插件是主要风险面 | 历史漏洞较多 | 静态，风险低 | 视产品而定 |
| 升级方式 | 后台一键 + 回滚 | 后台一键 | 手工覆盖 | `git pull` 重生成 | 手工覆盖 |
| 许可证 | MIT | GPL | 部分版本有授权限制 | MIT 类 | 各异 |

## 逐个别说明

### vs WordPress

**它更强的地方**：生态。你要的任何功能，几乎都有插件；任何样式，几乎都有主题。评论、会员、电商、多语言，全是现成的。

**它更弱的地方**（对你可能重要的）：

- 动态渲染，访客一多就吃 CPU，虚拟主机上很容易 502
- 必须配伪静态
- 插件是主要攻击面——大量漏洞来自第三方插件，而不是 WP 本身
- 后台偏"西式"，栏目、推荐位这些概念得重新学

**怎么选**：要评论、要多作者、要现成插件 → WordPress。只要"写文章 + 好看 + 快 + 稳" → CiciCMS 更省心。

### vs 织梦 / 帝国

**它们更强的地方**：功能全，模型灵活（自定义字段、多级栏目、会员、采集），国内资料多，老站长熟。

**它们更弱的地方**：

- 后台逻辑偏重，新手要学一阵
- 织梦的历史版本有过不少安全事件，很多站因为没跟上补丁被挂马
- 采集、会员这些功能大部分人根本用不上，但复杂度一直在那儿

**怎么选**：要做门户、要多级栏目和自定义模型 → 帝国更合适。做个人站/企业站，只用得到 20% 功能 → CiciCMS 更轻。

### vs Hexo / Hugo

**它们更强的地方**：纯静态的极致。生成快、零后台、Git 管理、可以白嫖 GitHub Pages。

**它们更弱的地方**：

- **没有后台**。写文章要在本地建 md 文件，跑命令生成，再推上去
- 换台电脑就得重新配环境
- 图片管理、附件、友链这些要自己想办法
- 不会命令行的人基本用不了

**怎么选**：你自己写代码、喜欢 Git 工作流 → Hexo 很好。你要"打开网页就能写" → CiciCMS。

::: tip 其实可以配合
CiciCMS 自带 Hexo 导入，从 Hexo 搬过来不用重写文章；反过来想走，数据库也能导出成标准 SQL 或 md。
:::

### vs 常见国产 CMS（PbootCMS 之类）

**它们更强的地方**：同样是"装完就能用"，模板标签体系类似，社区和教程多。

**差别在哪**：

- 它们多数是**动态**的，前台每次访问都查库；CiciCMS 生成静态文件
- CiciCMS 的三区权限模型（代码区只读、内容区可写）分得更清楚，升级不容易误伤
- CiciCMS 内置在线更新 + 回滚 + 邮件通知，这套东西一般要付费版才有

## 什么情况下**不该**选 CiciCMS

说清楚这些，比夸自己有用：

| 你的需求 | 建议 |
| --- | --- |
| 要评论、要用户注册、要多作者分工 | 别选。这套没做，硬加要改不少代码 |
| 要电商、在线支付、订单 | 别选。完全不是这个方向 |
| 内容每分钟都在变（实时资讯、行情） | 别选。生成跟不上变化 |
| 要多级栏目、自定义内容模型 | 别选。栏目只有一级，字段是固定的 |
| 团队里没人会一点 HTML | 谨慎。默认主题能直接用，但改样式需要 HTML |
| 需要极成熟的插件生态 | 选 WordPress |
| 想完全不用服务器、白嫖静态托管 | 选 Hexo + GitHub Pages |

## 什么情况下**特别适合**

- 你买的是几百块的虚拟主机，只给 PHP + MySQL
- 你的站是"文章型"，一天更新几篇，不是每分钟
- 你在意打开速度和 SEO
- 你不想维护一堆插件、缓存、伪静态
- 你想升级的时候不用登 FTP
- 你希望数据库挂了前台还能看
